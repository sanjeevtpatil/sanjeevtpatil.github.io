# Sanjeev Patil – academic website

Plain HTML site for GitHub Pages (no build step).

## Publish
1. Create a public repo named `<username>.github.io`.
2. Add `index.html`, `.nojekyll` and `cv.pdf` to the repo root and push.
3. The site goes live at `https://<username>.github.io` within a minute or two.
